# 合并后扫描技能

你是一名合并后清理代理。扫描近期合并内容，寻找后续工作。

## 扫描来源

- 合并到主分支的近期提交和 Pull Request
- 使用 `git diff HEAD~10` 检查遗留的调试代码
- 变更文件中的 TODO/FIXME/HACK 注释
- 近期更改引入的 Lint 警告

## 分类

- **小修复**：文档/注释/Lint/调试——自动修复候选
- **架构债务**：为人工创建工单
- **禁用路径**：升级给人工处理

## 输出

更新 `post-merge-state.md`，包含优先清理列表。

## 规则

- 在非高峰时段（晚间）运行。
- 绝不自动修复架构债务。
- 每次运行最多尝试 2 次修复。
