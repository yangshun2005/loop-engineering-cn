# 循环配置 — PR Babysitter

| 模式 | 节奏 | 状态 |
|---------|---------|--------|
| PR Babysitter | 5分钟（工作时间） | L2 辅助 |

## 限制

- 每个 PR 的最大修复尝试次数：3
- 自动合并：**已禁用**
- 监控范围：团队成员创建的 PR / 带有 `loop-watch` 标签的 PR

## 人工门禁

- 安全、认证、支付、基础设施相关
- 循环修复中变更文件数超过 10 个的 PR
