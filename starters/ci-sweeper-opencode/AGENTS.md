# AGENTS.md — CI 清理器（Opencode）

## 循环模式
- CI 清理器是第 1 周的第 2 级任务（行动导向 — CI 问题紧急）。
- 每次运行前阅读 `ci-sweeper-state.md`。
- 在尝试任何修复之前，先对失败进行分类。

## 安全
- 每次尝试务必分发到独立的 git worktree 中。
- 基础设施 / 安全 / 支付测试失败：不要自动修复；标记并停止。
- 每个项目最多尝试修复 3 次；之后升级处理。
- 遵守 `LOOP.md` 中的预算上限。

## 验证
- 验证者必须在实施者之后运行测试。
- 在 `ci-sweeper-state.md` 中记录尝试次数。
- 未经验证者批准，不得自动合并。
