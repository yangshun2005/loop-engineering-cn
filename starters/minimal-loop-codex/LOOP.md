# 循环配置 — 最小分诊（Codex）

## 活动循环

| 模式 | 节奏 | 状态 | 自动化提示 |
|---------|---------|--------|-------------------|
| 每日分诊 | 1天 | L1 仅报告 | `运行 $loop-triage。读取 STATE.md。仅报告。` |

## 人工门禁

- 在 L2 检查清单完成之前，不进行自动修复
- 所有高风险路径：必须人工审核（参见 docs/safety.md 中的禁用列表）

## 工作树

- Codex 为每个线程提供内置工作树 — 用于 L2 及以上的修复尝试。
- 每个工作树只进行一次修复；验证子代理必须批准后才能提出 PR。

## 连接器（MCP）

- MCP 对于 L1 仅报告循环是可选的。
- 对于 L2 及以上：使用 GitHub 连接器读取 CI/Issue；在受信任之前，写入范围仅限于评论。

## 预算

- 每次运行的最大子代理生成数：0（L1）
- 每日查看 STATE.md + Codex 分诊收件箱
