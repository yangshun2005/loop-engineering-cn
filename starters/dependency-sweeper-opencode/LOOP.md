# 循环配置 — 依赖清理器（Opencode）

## 活动循环

| 模式 | 频率 | 状态 | 命令 |
|---------|---------|--------|---------|
| 依赖清理器 | 6小时 | L2 仅补丁 | `opencode run "运行依赖分类" --agent loop-triage` 通过 cron |

## 人工门禁
- 主版本升级始终由人工处理。
- 需要破坏性变更的高严重性 CVE：由人工处理。
- 禁用列表中的包（在状态中编辑）绝不会被自动触碰。
- 未经验证器通过，不得自动合并。

## 工作树
- 每次包更新尝试使用一个工作树。
- 在拒绝或升级至人工处理时丢弃。

## 预算
- 每次运行的最大子代理生成数：3。
- 每天最大自动 Pull Request 数：5。
- 若超出令牌预算则暂停。
