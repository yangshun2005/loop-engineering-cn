## 人工门禁

- 主版本升级 → 始终需要人工审批
- 需要破坏性变更的高严重性 CVE → 需人工处理
- 禁用列表中的包（在状态文件中编辑）→ 绝不自动触碰
- 未经验证器通过及允许列表确认，不得自动合并

## 工作树

- 每次包更新尝试使用一个工作树
- 在 REJECT 或升级至人工处理后，丢弃工作树

## 预算

- 每次运行最大子代理生成数：3
- 每天最大自动 Pull Request 数：5
- 若超出令牌预算则暂停（参见 `templates/loop-budget.md.template`）
