# LOOP.md — 精简循环

- **模式：** 精简循环
- **级别：** L1 仅报告
- **节奏：** `issues`/`pull_request` 打开时 + 工作日 08:00 UTC
- **状态：** 无。GitHub Issues 和 PR 即待办事项。Actions 任务摘要即为报告。
- **写入：** 任务摘要；每个线程至多一条评论（`<!-- thin-loop -->`）。
- **禁止操作：** 不编辑代码、不添加标签、不关闭、不推送。
- **终止开关：** 禁用 `.github/workflows/thin-loop.yml` 或取消工作流。

当队列必须在多次运行间持续存在（如尝试次数、预算、监视列表）时，请升级至每日分类并添加 `STATE.md`。
