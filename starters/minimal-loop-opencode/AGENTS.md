# AGENTS.md — Opencode 最小循环

这些规则在循环工作开始前由 opencode 加载。

## 循环模式

- 从 L1 仅报告模式开始。
- 在任何分诊之前，先阅读 `STATE.md`。
- 每次循环运行后更新 `STATE.md`。
- 在人工明确启用 L2 之前，不要编辑源代码。

## 安全

- 未经人工批准，切勿推送或合并。
- 切勿编辑 `.env`、`.env.*`、`auth/`、`payments/`、`secrets/` 或 `credentials/`。
- 每次尝试修改代码时，使用 git worktree。
- 每个项目最多尝试修复 3 次；超过后升级处理。

## 验证

- 对于 L2+ 的更改，在实施后派遣一个验证子代理。
- 在提出修复方案之前，运行项目文档中记录的测试。
- 在 `STATE.md` 中记录测试证据。
