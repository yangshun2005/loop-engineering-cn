# 循环配置 — 最小化分诊（Claude Code）

## 活动循环

| 模式 | 节奏 | 状态 | 命令 |
|---------|---------|--------|---------|
| 每日分诊 | 1天 | L1 仅报告 | `/loop 1d 运行 $loop-triage` |

## 人工门禁

- 在 L2 检查清单完成之前，不进行自动修复
- 所有高风险路径：必须人工审核（参见 docs/safety.md 中的禁用列表）

## 工作树

- 在生成实施者子代理（L2+）时，使用 `isolation: worktree`。
- 每次修复尝试使用一个工作树；验证者拒绝后丢弃。

## 连接器（MCP）

- MCP 对于 L1 仅报告循环是可选的。
- 对于 L2+：使用 GitHub MCP 读取 CI/Issue；在受信任之前，将连接器范围限制为仅读取和评论。

## 预算

- 每次运行的最大子代理生成数：0（L1）
- 每日审查 STATE.md
