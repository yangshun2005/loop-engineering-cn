# AGENTS.md — PR 保姆（Opencode）

## 循环模式
- 以 L1 仅报告模式开始。
- 在任何分类操作之前，先阅读 `pr-babysitter-state.md`。
- 在人类明确启用 L2 之前，不要编辑源代码。

## 安全
- 未经人类明确同意，切勿强制推送。
- 默认创建草稿 PR；由人类标记为准备审查。
- 未经批准，不得解决审查线程。
- 涉及安全、认证、支付、基础设施或公共 API 的更改始终升级处理。
- 每个 PR 最多尝试修复 3 次，之后移交处理。

## 验证
- 对于 L2+ 更改，在实施后派遣验证子代理。
- 在提出修复建议之前，运行项目文档中记录的测试。
- 在推送之前，检查是否存在针对相同意图的现有 PR。
